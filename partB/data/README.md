# Dataset README

## Dataset: Synthetic Short-Answer Grading Dataset

### What is this dataset?
A synthetic dataset of (question, reference_answer, student_answer, grade) tuples generated programmatically for reproducing the short-answer grading system from Mohler et al. (ACL 2011).

### How is the dataset obtained?
The dataset is generated by the `build_toy_short_answer_dataset()` function in `grading_model.py`. No external download is required.

To regenerate:
```python
from grading_model import build_toy_short_answer_dataset
df = build_toy_short_answer_dataset(n_per_question=50, random_state=42)
df.to_csv("data/short_answer_dataset.csv", index=False)
```

### Dataset structure
| Column | Type | Description |
|--------|------|-------------|
| question | str | The question text |
| reference_answer | str | Instructor's correct answer |
| student_answer | str | Student's response (generated via mutation) |
| grade | float | Continuous grade in [0, 5] |

### How is it used?
- **task_2_1.ipynb**: Generation, exploration, and visualisation
- **task_2_2.ipynb**: Training SVR model on 80% split
- **task_2_3.ipynb**: Evaluation on 20% test split
- **task_3_1.ipynb**: Ablation experiment comparisons
- **task_3_2.ipynb**: Normal training data (paraphrase challenge set is generated separately)

### Paraphrase Challenge Set
A separate small dataset of 6 paraphrased answers with low lexical overlap is generated by `build_paraphrase_challenge_set()` for the failure mode experiment in task_3_2.
